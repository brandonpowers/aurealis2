# Aurealis2 Project Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the uncommitted, 5-month-stale Aurealis2 working tree into a committed, dependency-fresh repository with a redesigned pro-audio UI and a shippable standalone web visualizer.

**Architecture:** The C++ DSP (untouched this cycle) feeds a Three.js point-cloud renderer via SPSC ring buffer in plugin mode, or a Web Audio analysis path in standalone mode. All UI work happens in `Aurealis2/resources/web/` — pure HTML/CSS/JS with no build step so the same files run in a browser and (later) inside an iPlug2 WebView. Verification is screenshot-driven: a 7-checkpoint Puppeteer harness plays a synthesized reference WAV and captures the render at known signals.

**Tech Stack:** C++17/CMake/ctest (DSP), Three.js 0.185.1 (vendored ES module), Puppeteer + headless Chrome (visual tests), ffmpeg (test/demo audio synthesis), Python http.server (dev serving).

## Global Constraints

- **Frozen:** the aurealis hue formula `fract(log2(freq/440) + colorTune)`, all positional mappings (freq→Y, stereo→X, time→Z), density compensation `pow(rawWeight, 0.4)`, and stereo-spread behavior. The 7 visual checkpoints must keep identical structure, position, and hue after every task.
- **No build step, no CDN, no framework** in `Aurealis2/resources/web/` — plain ES modules only, all assets local (WebView compatibility).
- Three.js pinned at **0.185.1**, vendored in `Aurealis2/resources/web/lib/` (two files: `three.module.js` + `three.core.js`).
- Web server for all tests: `localhost:8080` serving `Aurealis2/resources/web/`.
- Visual harness must be re-run after ANY change to `Aurealis2/resources/web/shaders/` or `js/renderer.js`/`js/spectrogram.js`. DSP tests (`ctest`) after any change under `Aurealis2/dsp/` (none planned).
- `test.mp3` (unknown provenance) is never committed, never referenced by shipped code. `test-reference.wav` is never committed (regenerated by script).
- Commit messages: plain imperative mood, no prefix convention (matches existing "Add project refresh design spec").
- Design tokens (Task 5) are the single source of truth for colors/type; later UI tasks must use `var(--…)`, never hard-coded colors.
- This repo has **no git remote** — CI changes are verified by running their steps locally; pushing is the user's decision.

- [ ] **Step 1: Write the failing UI test harness**

Create `Aurealis2/scripts/run-ui-tests.mjs`:

```js
#!/usr/bin/env node
// UI state tests for the Aurealis2 web app. Companion to run-visual-tests.mjs
// (which verifies the DSP/render pipeline; this verifies chrome/UI states).
//
// Usage: node Aurealis2/scripts/run-ui-tests.mjs [--port 8080] [--out /tmp]
// Each test gets a fresh page. Screenshots land in <out>/ui-<slug>.png.

import puppeteer from 'puppeteer';
import { parseArgs } from 'node:util';
import path from 'node:path';

const { values: opts } = parseArgs({
    options: {
        port: { type: 'string', default: '8080' },
        out:  { type: 'string', default: '/tmp' },
    },
});

const BASE = `http://localhost:${opts.port}`;
const tests = [];
function test(name, fn) { tests.push({ name, fn }); }
const slug = (s) => s.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '');

// ---------------------------------------------------------------- tests --

test('page loads without errors and design tokens are defined', async (page) => {
    await page.goto(`${BASE}/index.html`, { waitUntil: 'networkidle0', timeout: 30000 });
    const accent = await page.evaluate(() =>
        getComputedStyle(document.documentElement).getPropertyValue('--accent').trim());
    if (!accent) throw new Error('--accent token not defined on :root');
});

test('bundled fonts are loaded', async (page) => {
    await page.goto(`${BASE}/index.html`, { waitUntil: 'networkidle0', timeout: 30000 });
    await page.evaluate(() => document.fonts.ready);
    const ok = await page.evaluate(() =>
        document.fonts.check('12px Inter') && document.fonts.check('12px "JetBrains Mono"'));
    if (!ok) throw new Error('Inter / JetBrains Mono not available after fonts.ready');
});

// ---------------------------------------------------------------- runner --

const browser = await puppeteer.launch({
    headless: 'new',
    args: ['--no-sandbox', '--enable-unsafe-swiftshader',
           '--autoplay-policy=no-user-gesture-required',
           '--use-gl=angle', '--use-angle=swiftshader'],
});

let passed = 0, failed = 0;
for (const t of tests) {
    const page = await browser.newPage();
    await page.setViewport({ width: 1280, height: 720 });
    const errors = [];
    page.on('pageerror', (e) => errors.push(e.message));
    try {
        await t.fn(page);
        if (errors.length) throw new Error('page errors: ' + errors.join('; '));
        await page.screenshot({ path: path.join(opts.out, `ui-${slug(t.name)}.png`) });
        console.log(`PASS  ${t.name}`);
        passed++;
    } catch (e) {
        console.log(`FAIL  ${t.name}: ${e.message}`);
        failed++;
    }
    await page.close();
}
await browser.close();
console.log(`\nUI tests: ${passed} passed, ${failed} failed`);
if (failed > 0) process.exit(1);
```

- [ ] **Step 1: Write the generation script**

Create `Aurealis2/scripts/gen-demo-audio.sh`:

```bash
#!/usr/bin/env bash
# Synthesize the bundled demo track for the Aurealis2 web app.
# 24 s, four layers designed to exercise every visual dimension:
#   - A-minor pad (A2+E3+A3+C4+E4) with slow tremolo  → harmonic color, saturation
#   - 2 Hz 80 Hz kick                                  → transient punch (Y/size)
#   - Off-beat noise hats, alternating L/R             → stereo spread, treble fill
#   - Slow arpeggio (A4/C5/E5/A5), one note per second → moving hue
# Requires: ffmpeg with lavfi + native AAC encoder.

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
OUT="${SCRIPT_DIR}/../resources/web/demo.m4a"
RATE=44100
DUR=24

PAD="0.16*(sin(110*2*PI*t)+sin(164.81*2*PI*t)+sin(220*2*PI*t)+sin(261.63*2*PI*t)+sin(329.63*2*PI*t))*(0.8+0.2*sin(0.5*2*PI*t))"
KICK="0.85*sin(80*2*PI*t)*pow(max(0,cos(2*PI*t)),8)"
ARP="0.22*sin( (440*lt(mod(t,4),1) + 523.25*between(mod(t,4),1,2) + 659.25*between(mod(t,4),2,3) + 880*gte(mod(t,4),3)) *2*PI*t)*(0.5+0.5*sin(1*2*PI*t))"

ffmpeg -y \
  -f lavfi -i "aevalsrc='${PAD}':s=${RATE}:d=${DUR}" \
  -f lavfi -i "aevalsrc='${KICK}':s=${RATE}:d=${DUR}" \
  -f lavfi -i "anoisesrc=color=white:duration=${DUR}:sample_rate=${RATE}:amplitude=0.18" \
  -f lavfi -i "aevalsrc='${ARP}':s=${RATE}:d=${DUR}" \
  -filter_complex "\
    [2]apulsator=hz=0.25:mode=square,volume='0.5*pow(max(0,sin(4*2*PI*t+PI)),6)':eval=frame,highpass=f=6000[hats];\
    [3]apulsator=hz=0.125[arps];\
    [0][1][hats][arps]amix=inputs=4:normalize=0,pan=stereo|c0=c0|c1=c1,alimiter=limit=0.9[out]" \
  -map "[out]" -ar "$RATE" -c:a aac -b:a 96k "$OUT" 2>/dev/null

echo "Done: $OUT ($(du -h "$OUT" | cut -f1))"
```

```js
#!/usr/bin/env node
// Measure real rendering FPS. Unlike run-visual-tests.mjs (SwiftShader software
// rendering, deliberately deterministic), this tries the actual GPU:
// headful Chrome when $DISPLAY exists, headless+EGL otherwise.
//
// Usage: node Aurealis2/scripts/measure-fps.mjs [--port 8080] [--seconds 12]

import puppeteer from 'puppeteer';
import { parseArgs } from 'node:util';

const { values: opts } = parseArgs({
    options: {
        port:    { type: 'string', default: '8080' },
        seconds: { type: 'string', default: '12' },
    },
});

const headful = !!process.env.DISPLAY;
const browser = await puppeteer.launch({
    headless: headful ? false : 'new',
    args: [
        '--no-sandbox',
        '--autoplay-policy=no-user-gesture-required',
        ...(headful ? [] : ['--use-gl=egl', '--enable-gpu', '--ignore-gpu-blocklist']),
    ],
});

const page = await browser.newPage();
await page.setViewport({ width: 1280, height: 720 });
await page.goto(`http://localhost:${opts.port}/index.html`, { waitUntil: 'networkidle0' });
await page.click('#landing-play-demo');
await new Promise(r => setTimeout(r, 3000)); // warm-up

const gl = await page.evaluate(() => {
    const c = document.createElement('canvas');
    const g = c.getContext('webgl2');
    const info = g?.getExtension('WEBGL_debug_renderer_info');
    return info ? g.getParameter(info.UNMASKED_RENDERER_WEBGL) : 'unknown';
});
console.log(`Renderer: ${gl}  (${headful ? 'headful' : 'headless+egl'})`);

const samples = [];
const n = parseInt(opts.seconds, 10);
for (let i = 0; i < n; i++) {
    await new Promise(r => setTimeout(r, 1000));
    samples.push(await page.evaluate(() => window.__aurealisDebug.getFPS()));
}
await browser.close();

const avg = samples.reduce((a, b) => a + b, 0) / samples.length;
console.log(`Samples: ${samples.join(' ')}`);
console.log(`Average: ${avg.toFixed(1)} fps   Min: ${Math.min(...samples)} fps`);
process.exit(avg >= 55 ? 0 : 1);
```
